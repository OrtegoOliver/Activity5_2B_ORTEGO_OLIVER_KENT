# Stacks and Queues: Array vs. Linked List

## Description

This project demonstrates stack and queue implementations using arrays and linked lists. It also includes a balanced-parentheses checker and a print queue simulation.

## Files

* array_stack.py – Implements an array-based stack.
* linked_stack.py – Implements a linked-list stack.
* array_queue.py – Implements a circular array queue.
* linked_queue.py – Implements a linked-list queue.
* balanced_parentheses.py – Checks whether parentheses are balanced.
* print_queue.py – Simulates printing jobs in FIFO order.
* analysis.md – Contains the written analysis.

## How to Run

1. Install Python 3.
2. Open a terminal in the project folder.
3. Run each file using python filename.py.
4. Test the operations and check the displayed results.

## Conclusion

Stacks follow the LIFO principle, while queues follow the FIFO principle. Both data structures are useful for organizing and processing data in computer programs.
